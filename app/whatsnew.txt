Shortcuts menu (Ctrl+Alt+Shift+H)
- The shortcuts button is now a small round button with the Vibelight icon. It starts hidden: Ctrl+Alt+Shift+H shows it, opens the menu and frees the mouse. A Settings option keeps it always on top instead (drag it anywhere).
- Tidier layout: a short top level with Pinned & recent and categories (Remote PC, Displays, Vibelight, Tools, My shortcuts, Clipboard). Click Back or press Esc to go up.
- Pin, recents, and your own custom shortcuts (edit them from the menu).
- Display and monitor shortcuts such as Win+P and Win+Shift+Left/Right.
- Check connection: watches the stream for 10 seconds and suggests a bitrate.
- Stream timer, host info and the version in the menu.
- Screenshot of the stream and a small latency graph (Windows).
- Clipboard history: type any of your last 10 copies on the remote PC.
- Clipboard sync: send your clipboard text to the host or get the host's, from the Clipboard page (needs Vibepollo or another Apollo-style host).
- File drop: drag a file onto the stream window to send it to the host's receive folder (needs Vibebeam with "Upload files" allowed for this client). The button shows the progress.
- Two-factor code: if the host turns on "Require 2FA to connect", Vibelight asks for the six-digit code when you start or resume a stream (needs Vibebeam).
- Get host clipboard: Ctrl+Alt+Shift+C (hide/show cursor moved to U).
- Typing mode: switch to key presses if text doesn't type into a terminal.

Connection
- Auto-reconnect: if the stream drops, Vibelight tries up to 3 times to resume.
- Hold left Ctrl+Alt+Z to release the mouse and move it outside the window.

Updates and support
- Check for updates and Download update buttons in Settings, with a bitrate suggestion.
- Install and restart: portable Windows installs can update themselves after the download (the old version is kept in .update-backup).
- Save a diagnostics file and open the log folder from Settings -> Support.
- Report a problem button opens a prefilled GitHub issue.
- Release notes on GitHub now include this list.

Settings
- Search box at the top of Settings filters the sections.
- Choose the letter used by the shortcuts menu hotkey (Ctrl+Alt+Shift+letter).

Look and feel
- New Vibepollo-style colors and cards, and a new icon.
